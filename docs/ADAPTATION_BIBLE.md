# 原著改编设定基线 2.0

默认以第一部电影的视觉、空地分工和迷宫压力为基础；小说的记录/解谜思路使用独立内容配置。所有游戏提示和简化谜题原创，不复制原作长篇文本、对白、图片、声音或模型。

范围核对：James Dashner《The Maze Runner》(2009)、Wes Ball《The Maze Runner》(2014)。本轮实际阅读了[小说情节二手梗概](https://en.wikipedia.org/wiki/The_Maze_Runner#Plot)、[电影情节二手梗概](https://en.wikipedia.org/wiki/The_Maze_Runner_(film)#Plot)，核对日期2026-10-17。没有逐章核验全部系列，也没有将二手来源当成完整原著阅读；未来精确密码、补给周期与后续组织细节仍需回到作品复核。

A=两版共同基线；B=电影改编；C=小说独有或采用小说版本；D=Minecraft合理改编；E=项目原创机制。状态中的“编码”不等于真实服务器实测。

## 内容配置边界

`match.profile`仅接受FILM或NOVEL。默认目标来自`objectives`，某profile可在`profiles.<版本>.objectives`完整替换目标集合；不能隐式拼接两套密码。FILM与NOVEL的briefing分别配置，NOVEL当前确有不同的依赖图。模式CORE/EXPERIMENT与内容版本正交，不把电影/小说当成两个复制代码的模式。

真正的原著地图规律、更多章节剧情和独立角色故事仍属于后续内容包，必须逐项注明出处和改编。不要把当前简化内容说成已经复刻整部小说或整个系列。
